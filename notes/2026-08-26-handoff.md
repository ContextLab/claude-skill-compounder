## Dead ends

- **Seeding a session by injecting conversation history does not work.** Injected
  `tool_use`/`tool_result` blocks are mangled: `-d api --debug-file` recorded
  `ensureToolResultPairing: repaired missing tool_result blocks (5 -> 5 messages)`, three
  injected assistant turns collapsed into one, and every injected tool_result was dropped
  and re-synthesised. A seeded session therefore cannot end on tool output; it answers the
  first user text instead. Rig the ENVIRONMENT so the moment arises from the session's own
  tool output. Do not retry history injection.
- **Wiring the claim gate's third arm (`PostToolUse`) is wrong**, even though the script
  handles it. Its accumulator records every long integer from any tool result, Agent and
  Task results included, which is exactly the subagent testimony the Stop arm must exclude.
  Wiring it would have stopped the gate catching relayed figures, i.e. all four genuine
  defects in its calibration. A test pins the decision on both install paths.
- **Making `skillforge start --trigger` a hard refusal is wrong.** Refusing does not produce
  a trigger, it produces no row at all: every caller written before the flag would exit 2,
  and the cheapest way past a refusing CLI is to stop calling it. The gap is recorded as
  `trigger_kind:"unrecorded"` instead. `SKILLFORGE_REQUIRE_TRIGGER=1` exists for anyone
  whose callers are all updated.
- **A brace group alone does not fix the lazy-read hazard.** Wrapped but with no terminating
  `exit`, bash resumes just past `}`, finds rewritten bytes, and runs the body a second
  time. Both halves are load-bearing.

## Watch out for

- **Never edit a script while it may be running.** Bash reads a script lazily by byte
  offset; a rewrite mid-run resumes execution inside the new bytes. This destroyed a real,
  paid-for session review on 2026-08-25 ($0.2221734, verdict lost). Hooks and the status
  line are invoked by absolute path into the checkout and the CLIs are symlinked to it, so
  an ordinary `git pull` is enough to trigger it.
- **The claim gate will block a commit whose message carries a >=3-digit figure that
  appears in no tool output this session.** The fix is to run the command and quote its
  output, not to delete the number. Restating it more firmly is the failure being caught.
- **A subagent's report is testimony, not measurement.** Five separate agents caught claims
  in this session that did not survive derivation, three of them relayed agent reports.
- **Do not run the full suite while agents are editing the tree.** Several agents were
  confused by red files belonging to someone else's in-flight work.
- **A failed `Skill` invocation reaches no hook at all** on CLI 2.1.245, so the live `use`
  census counts successes only; transcripts remain the source for failures.
